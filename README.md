# ملاحظاتي — My Notes

<div dir="rtl">

**ملاحظات لاصقة على سطح المكتب لويندوز**، بالعربي والإنجليزي.

## التحميل

حمّل أحدث نسخة من صفحة **[Releases](../../releases/latest)**: ملف `StickyNotes-Setup-…exe`.

- لا يحتاج صلاحيات مدير (Admin)، ويمكنك اختيار مكان التثبيت.
- يعمل على Windows 10 وWindows 11 (64-bit).

## المميزات

- ملاحظات بألوان وأشكال ورق، مع تنسيق النص (عريض، ألوان، عناوين، قوائم) وصور.
- قوائم مهام بمواعيد وتنبيهات وتكرار، وشاشة «يومي» لكل المهام.
- خزنة كلمات مرور مشفّرة (AES-256)، مع أكواد التحقق بخطوتين وتقرير أمان.
- بحث سريع، ونسخ سابقة لكل ملاحظة، ونسخ احتياطي يومي.
- مزامنة اختيارية بين الأجهزة، ووضع داكن.
